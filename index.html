POLÍTICA DE PRIVACIDADE

Última atualização: junho de 2025

1. Quem somos. Mini Craque IA é um serviço de criação de bonecos colecionáveis personalizados com IA, operado de forma independente no Brasil.

2. Dados coletados. Selfie enviada, dados de contato (WhatsApp ou e-mail) e dados de pagamento processados pelo Mercado Pago. Não armazenamos dados de cartão.

3. Uso dos dados. Exclusivamente para criar e entregar seu boneco. Não vendemos nem compartilhamos dados com terceiros para fins comerciais.

4. Segurança. Dados armazenados no Supabase com criptografia. Fotos em bucket privado, excluídas após 90 dias.

5. Seus direitos (LGPD). Acesso, correção, exclusão e revogação do consentimento. Entre em contato pelo WhatsApp.
